# Shedied-Poster 🧲

**Shedied-Poster** adalah plugin WordPress yang memungkinkan Anda untuk melakukan scraping konten dari situs web lain. Plugin ini dirancang untuk fleksibilitas tinggi, bebas digunakan, dan mudah dimodifikasi sesuai kebutuhan Anda.

---

## 🚀 Fitur Utama

- 🕸️ Scraping konten dari situs eksternal
- 🔧 Struktur fleksibel untuk pengembangan lanjutan
- 🔌 Mudah diintegrasikan ke dalam workflow WordPress
- 🆓 Bebas lisensi untuk penggunaan pribadi maupun komersial

---

## 🖥️ Persyaratan Sistem

- 🌀 WordPress 5.0 atau lebih baru  
- 🐘 PHP 7.3 atau lebih baru  
- 📦 Composer

---

## ⚙️ Instalasi

1. **Clone repository ini ke direktori plugin WordPress Anda:**

   ```bash
   git clone https://github.com/nama-user/shedied-poster.git wp-content/plugins/shedied-poster
   ```

2. **Masuk ke direktori plugin dan jalankan Composer:**

   ```bash
   cd wp-content/plugins/shedied-poster
   composer install
   ```

   ❗ Jika gagal menjalankan `composer install`, Anda dapat menggunakan file `vendor.zip` yang telah disediakan. Ekstrak isi `vendor.zip` ke dalam folder plugin sehingga struktur foldernya menjadi seperti ini:

   ```
   wp-content/plugins/shedied-poster/
   ├── vendor/
   ├── src/
   ├── shedied-poster.php
   └── ...
   ```

3. **Aktifkan plugin melalui Dashboard WordPress:**

   - 🔍 Masuk ke **Plugins > Installed Plugins**
   - 📌 Temukan **Shedied-Poster**
   - ✅ Klik **Activate**
